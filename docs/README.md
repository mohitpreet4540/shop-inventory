# Shop Inventory Documentation Hub
Use this index to navigate the project documentation as a newcomer or contributor.

## Who this is for
- New developers onboarding to the project
- Contributors planning features or bug fixes
- Maintainers who need a quick project and roadmap snapshot

## Start here (recommended order)
1. `../README.md` — high-level project summary and API quick reference
2. `GETTING_STARTED.md` — run the project locally with Docker or Python
3. `ARCHITECTURE.md` — understand backend/frontend/data design
4. `../CONTRIBUTING.md` — coding workflow and change process
5. `ROADMAP.md` — where the project is going next

## Documentation map
- Project summary + setup: `../README.md`

## When updating docs
Update docs in the same PR whenever you change:
- API endpoints or payload contracts
- Environment variables
- Setup/run commands
- Architecture boundaries (models/routers/frontend flow)
